Python Data Analysis Toolkit

NumPy | Pandas | Matplotlib

A hands-on Python learning repository covering numerical computing, data manipulation, data cleaning, file handling, and data visualization — from fundamental concepts to advanced practice.

About This Repository

This repository contains my structured practice and learning work with three essential Python libraries used in data analysis and AI/ML.

Rather than limiting my learning to theory, I focused on writing code, exploring practical examples, working with datasets, and applying these concepts through hands-on exercises and projects.

Technologies Used

- Python — Core programming language
- NumPy — Numerical computing and array operations
- Pandas — Data manipulation, analysis, and file handling
- Matplotlib — Data visualization and plotting
- Jupyter Notebook — Interactive coding and experimentation

Repository Contents

1. NumPy

A collection of six learning notebooks covering foundational to advanced concepts, along with a practical data-cleaning project.

Topics include:

- NumPy arrays and array creation
- Array indexing and slicing
- Array operations and mathematical functions
- Data manipulation and numerical operations
- Practical coding exercises
- Data cleaning using a real-world-style employee dataset

2. Pandas

A collection of learning notebooks covering data analysis and file handling.

Topics include:

- Series and DataFrames
- Data selection, filtering, and indexing
- Data manipulation and transformation
- Handling missing values and duplicate records
- Data cleaning and preprocessing
- Reading and writing CSV and other supported file formats
- Practical dataset analysis

3. Matplotlib

Six learning notebooks covering data visualization techniques.

Topics include:

- Basic plotting
- Line plots
- Bar charts
- Scatter plots
- Plot customization
- Titles, labels, legends, and grids
- Creating clear and informative visualizations

Getting Started

Navigate to the project directory:

cd Python-Data-Analysis-Toolkit

Install the required libraries:

pip install -r requirements.txt

Launch Jupyter Notebook:

jupyter notebook

Open any notebook to explore the code and learning exercises.

Requirements

The main libraries used in this repository are:

- pandas
